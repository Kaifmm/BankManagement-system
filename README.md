
# 🏦 Bank Account Management System

A console-based **Bank Account Management System** developed using Core Java and Object-Oriented Programming (OOP) concepts. This project allows users to create and manage bank accounts, deposit and withdraw money, transfer funds, and manage different types of accounts through a menu-driven interface.

## 🚀 Features

- **Create Bank Account:** Create and manage bank accounts.
- **Display Account Details:** View account information.
- **Deposit Money:** Deposit money into an account.
- **Withdraw Money:** Withdraw money based on account rules.
- **Transfer Money:** Transfer money between accounts.
- **Savings Account:** Manage savings accounts with interest rate calculation.
- **Current Account:** Manage current accounts with an overdraft/draft limit.
- **Duplicate Account Validation:** Prevent duplicate account IDs.
- **Account Management:** Store and manage multiple account objects using arrays.

## ⚙️ How to Run the Project

### Prerequisites

- Java Development Kit (JDK) installed
- IntelliJ IDEA or another Java IDE

### Steps

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project in IntelliJ IDEA.
3. Ensure all Java classes belong to the correct package.
4. Run the `main.java` file.
5. Follow the menu displayed in the console to perform banking operations.
